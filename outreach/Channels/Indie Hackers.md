# Indie Hackers

**Status:** not started
**URL:** indiehackers.com

The default forum for bootstrapped founders. Founded 2016 by Courtland Allen, acquired by Stripe, bought back and run independently since 2023, which is why it still reads like a community rather than a content farm.

## How to use it

Not for launches. For build-in-public posts that document a decision, since this audience rewards specifics about revenue, architecture and mistakes. A post about *why the co-signer runs as a separate user on a separate account* is on-brand here in a way that a product announcement is not.

## Adjacent

- **WIP** — wip.co. Smaller, paid, shipping accountability through public logs. Suits a "build every day, outreach every day" discipline better than any other community on this map
- **StartupSauce**, **FounderLed**, **Founders Network** — paid masterminds, worth it only once there is real operational detail to discuss
