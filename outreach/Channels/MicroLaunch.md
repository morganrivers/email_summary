# MicroLaunch

**Status:** not started
**URL:** microlaunch.net

Small, indie, low-ceremony launch platform. Sits with TinyLaunch and TinyStartups in the "soft launch" tier.

## Use

Not for the big moment. Use it to shake out bugs and test whether the copy lands, before spending a [[Product Hunt]] or [[Show HN]] slot you only get once. Traffic is modest and the audience is other makers, which makes it a safe place to be imperfect.
